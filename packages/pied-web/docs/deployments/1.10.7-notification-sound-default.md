# Deployment: quiet notification default 1.10.7

NextSnapMail **0.1.15** and Pied Web **1.10.7** were installed on the n0c
production instance on 2026-09-21. New-mail sound notifications now default to
off. The two existing shared account-setting profiles were also written with
`SoundNotification=false`; linked accounts inherit their main account's shared
setting. Users can still turn the sound back on from General settings.

## Verification and limit

- Nextcloud is installed, outside maintenance mode and reports no pending
  database upgrade; NextSnapMail reports 0.1.15;
- both settings files contain the explicit false value, with no invalid,
  missing or true value;
- the final read-only audit matches **94 of 94** tracked files, reports the two
  Calendar 6.6.1 bundles patched, and validates Mail cache, multi-domain CSP and
  every `.htaccess` marker;
- the two Calendar bundles served over HTTPS have the patched SHA-256 values;
- all five aliases redirect to HTTPS as expected and return exactly one preload
  HSTS header; the scanner probe returns 410, while status, login, CalDAV and
  WebDAV keep their expected responses;
- Calendar's integrity command reports only the two expected modified bundles.

Authenticated browser verification could not be completed in this run:
`dev-browser-agent` timed out on its first connection to the persistent Chrome
profile. The browser rule forbids repeated connection attempts and an isolated
browser cannot replace the authenticated profile. Consequently the disk state
and explicit existing settings are verified, but LiteSpeed's live OPcache value
for the new PHP default and the visible General-settings switch were not
observed. Current profiles are still quiet even if an old PHP class remains in a
worker, because that older class also honors their now-explicit false setting.

## Rollback

For a preference-only rollback, first confirm the current account-settings
count and fingerprints, then restore only the two private `settings` files from
the protected backup. This restores the exact prior absence of the key without
touching accounts, credentials or mail. A user can also re-enable the switch in
General settings.

For a code rollback, do not silently downgrade the app after its recorded
upgrade. Prepare a forward release that restores the true default, or, during a
controlled maintenance window, restore the four backed-up runtime/version files
and validate Nextcloud's installed app-version state before reopening the site.
Any changed PHP requires the current authenticated targeted OPcache procedure.
Calendar 6.6.1 and Preview Generator 5.15.0 are separate App Store upgrades;
do not replace them with old directories. The Calendar patch can be reverted
only through the version-aware script and its exact 6.6.1 fingerprints.
