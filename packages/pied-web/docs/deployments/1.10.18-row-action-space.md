**0.1.15**, SnappyMail **2.38.2**. It completes the [row-space change](1.10.15-row-action-space.md):
desktop text uses the hidden action space at rest, and controls float over a
faded trailing edge on hover or keyboard approach. The global Feed only fades
a row while that row actually holds the shared action group, including the
initial keyboard cursor and departure to another row.
