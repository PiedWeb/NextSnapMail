## Restore the previous installed version

Run as the existing Nextcloud installation owner, on that host:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.6.6-20260912T180030Z/rollback.py"
```

This restores the backed-up 1.6.5 plugin and theme and removes the new `AttachmentImage.php`.
Account, Sieve and calendar settings are preserved. Finish/cancel pending outgoing messages
before changing versions. Reload the webmail after restoration. The GitHub `v1.6.5` release
also preserves that payload independently of the server backup.
