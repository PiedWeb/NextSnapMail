# Deployment 1.8.5, 2026-09-17

The Inbox now has an independent **Unread: oldest first** preference beside
**Conversations**. When enabled, unread received messages on the current native page
are chronological, then read messages remain reverse chronological. Unread Draft
reminders use the matching ascending server query while staying in their separate,
folder-safe section.

## Boundaries

Received rows are sorted within each native Inbox page; SnappyMail pagination remains
authoritative. Draft reminders stay separate because Inbox and Drafts UIDs can collide.
Search results, opened thread detail and other folders keep their native order. Fixture
mail is fictional; production checks evaluated only read/unread/date metadata already in
the list and did not print or copy message content.
