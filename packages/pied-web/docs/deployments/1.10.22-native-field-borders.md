# Deployment: native form borders, 2026-10-06

Pied Web **1.10.22** completes the one-pixel boundary rule in the native
composer. The 1.10.18 change had thinned focus outlines but left Nextcloud's
preserved two-pixel input and recipient-list borders in place. Version 1.10.21
corrected those borders; the final 1.10.22 additionally handles the editor mode
select's important button border and toolbar focus outline.

Compatibility: Nextcloud **34.0.4**, NextSnapMail **0.1.15**, SnappyMail **2.38.2**.
Source commits: `f06012c4e`, `89aa6df81`.
Release/tag: `piedweb-mail-v1.10.22`.

## Behavior and validation

Native input, select, textarea, editable and recipient-list boundaries use
one pixel. Focus strengthens the existing border colour through `--pw-focus`
without a second outline. Recipient lists own the focus boundary; their inner
text entry stays borderless. Unchecked native checkbox, alert and virus-warning
contours also use at most one pixel. Icon strokes and message content are not
changed. Existing sender hierarchy and releases 1.10.19–1.10.20 are preserved.

The complete monorepo suite, release fingerprints, reproducible theme build and
release packaging passed. Fictional native-template browser checks passed:
17 recipient checks, six tab checks and 19 inline-reply checks. The recipient
fixture now wraps Cc/Bcc/Reply-To with the native list structure as well as To.
Computed border widths and focus states were checked at 1440 and 390 px in light
and dark mode; the actual native editor select is covered by the inline fixture.
Transport is mocked in these fixtures; no real send is exercised.

Authenticated live inspection first confirmed two-pixel From, To and Subject
boundaries. After deployment, live native From, To, Cc, Bcc, Subject, HTML select
and editor DOM all reported one pixel on every side, the stronger focus colour,
no focus outline, and zero-pixel recipient inner borders. A freshly loaded
production stylesheet was applied to the task-owned open composer to preserve
its draft while checking the final select state. No field content was edited
and no Send, Save or Delete command was issued during those checks.

Fresh pages on **nc.robin-d.fr** and **cloud.piedweb.com** automatically loaded
the final theme focus marker after temporary maintenance cleanup. Authenticated
PHP checks on each origin initially retained 1.10.21; targeted OPcache
invalidation followed by a new request confirmed **1.10.22** on both. Other
origins were not checked. Cleanup restored the original private configuration
bytes and removed the temporary helper.
