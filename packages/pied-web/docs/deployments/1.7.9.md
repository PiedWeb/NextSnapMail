## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.9-20260914T113030Z/rollback.py"
```

The script verifies the current 1.7.9 and saved 1.7.8 fingerprints before
restoring the two files. Then follow `tools/web-runtime-maintenance/README.md`
to invalidate the restored `index.php` in the authenticated Web runtime,
reload Mail and check its served version and button state. The rollback does
not alter messages, accounts or server configuration.
