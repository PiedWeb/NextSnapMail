```sh

```

The script verifies all current 1.7.21 payload hashes and the saved 1.7.20
files before restoring only the three changed files. Then follow
`tools/web-runtime-maintenance/README.md` to invalidate the restored PHP class
in the authenticated Web runtime and reload Mail.
