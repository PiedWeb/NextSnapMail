# Automatic Inbox conversations, 26 October 2026

Pied Web **1.10.41** is installed on Nextcloud **35.0.2**, NextSnapMail
**0.1.16**, SnappyMail **2.38.2**.

The 1.10.40 discovery fix could find a historical Sent reply, but an Inbox reader
still required View full exchange when native list grouping was disabled.
Opening an Inbox message now automatically displays its latest received/sent
message with earlier history folded. The reader no longer depends on useThreads;
the native list preference and grouping requests are preserved. Navigating
directly to Sent leaves the Inbox conversation even if the same reply was active.
Other folders keep individual reading and the explicit full-exchange action.

View full exchange, automatically selects the expected native Sent reply and
shows the original history card. For this regression check only, the exposed
client useThreads getter was overridden to false, then restored; no stored
grouping preference was changed. Both inspected messages were already read.
The actual downloaded JS matches the compilation fingerprint below, contains
the automatic-reader change and no maintenance code. Mail flags are unchanged.
