# Refactoring UI review, 20 October 2026

Pied Web **1.10.33** targets Nextcloud **35.0.2**, NextSnapMail **0.1.16** and
SnappyMail **2.38.2**. The review used Adam Wathan and Steve Schoger's
*Refactoring UI*, independent visual/technical assessments and native contract
inspection. Preserve the established palette, reading measure, native commands,
account boundaries and message content.

## Changes

The implementation addresses 17 findings: truthful mobile scope; one global title
and refresh; progressive phone selection; two-line global subjects; full accessible
row labels and explicit unread conversation state; separate account/folder touch
targets; keyboard access for native navigation; a perceptible read indicator;
quiet composer discard against current core CSS; labels and validation on generated
recipient inputs; stronger field boundaries; full-width nested mobile selectors;
visible autosave failure guidance; Feed/search recovery actions; rem text and
wrapping chrome; advanced editor modes in More on narrow screens; natural plurals.
