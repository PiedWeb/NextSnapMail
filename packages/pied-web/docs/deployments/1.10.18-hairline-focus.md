# Mail: one-pixel focus and quieter senders, 2026-10-06

Pied Web **1.10.18** uses one-pixel outlines with solid, stronger focus ink.
Native/global sender text uses a quieter neutral than the subject, including
selected and checked rows. The composer editor changes its existing border
colour without adding an outer ring. Tab lines, global checked-row edges and
followed-row accents also use one pixel.

Compatibility: Nextcloud **34.0.4**, NextSnapMail **0.1.15**, SnappyMail **2.38.2**.
The sender neutral mixes 68% foreground into the background, replacing 76% and
full foreground on selected rows. Focus mixes equal foreground and primary
colour, with full opacity. Native checkbox tick strokes remain glyphs.
