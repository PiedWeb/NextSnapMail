# Native navigation compatibility, 20 October 2026

Pied Web **1.10.31** restores the search toolbar and folder navigation after
installing NextSnapMail **0.1.16** on Nextcloud **35.0.2** (SnappyMail 2.38.2).
No native core, account configuration or message was changed.

## Cause and change

Core 0.1.16 introduced three simple-search scope radios inside the search
wrapper. Studio relocates that wrapper into its fixed-height toolbar, outside
`.messageList`, leaving the new controls unstyled and pushing the input above
the viewport. The imported native fragment reproduced an input top of
**−14.72 px** at 1440 px. With the fix it is **10.5 px**, fully visible.
Scope remains available in the native Advanced search popup, alongside the
existing account/global scope. Native search handlers are unchanged.

The native folder-only unread filter also changed from `.e-checkbox` to a
bound `.folder-list-filter` label. Extend the established full-folder-list
presentation and compact-rail exclusion to the new selector. Both additions
remain native bound nodes and reappear when leaving the Pied Web theme.
