# Deployment 1.8.6.1, 2026-09-18

The Inbox mixed-order preference now has a per-account read-transition choice under
**Settings → General → Message list**. Mode 1 is the default and keeps a row in place
until the native list refreshes. Mode 2 holds only the open row, then reclassifies it
after the reader leaves while anchoring the newly opened row in the viewport.

## Boundaries

The transition choice applies only while **Unread: oldest first** is active in the ordinary
Inbox feed. Mode 1 defers reclassification until a list refresh; mode 2 releases the open
row only when the reader leaves it. Draft reminders, searches, thread detail and other
folders retain their existing boundaries. Fixture mail is fictional.
