# Deployment: message text width at rest, 2026-10-06

The row-space change was first installed as an intermediate **1.10.15** payload
on Nextcloud **34.0.4**, NextSnapMail **0.1.15**, SnappyMail **2.38.2**.
Native desktop rows recover **104 px** by replacing the permanent 128 px action
reservation with the normal 24 px gutter. The global Feed removes its 106 px
action column. Sender, subject and metadata use that space at rest; on hover or
keyboard approach, controls float over a faded trailing edge without rewrapping
subjects or moving following rows. Mobile/touch controls retain their layout.

This follows Schoger/Wathan, *Refactoring UI*, pp. 77 and 96–99. Implementation
commit: `70dd5f738`. The complete monorepo suite passed, with **25 selection**,
**30 mailbox workspace**, **13 desktop scanning** and **24 Feed** fixture checks.
Light rest/hover and dark focused crops with fictional content were inspected.
At 1000 px the native row and content widths stayed identical on approach; RTL
uses a fade towards the logical end. Native mail transport was mocked in fixtures.

The first audit matched **94/94**. Installation compared all **63** previous
1.10.14 payload fingerprints and installed only `feed-workspace.js`, the theme
stylesheet and the version-bearing plugin `index.php`, with PHP last. Native CLI
compilation passed. Both **cloud.piedweb.com** and **nc.robin-d.fr** initially
executed cached PHP 1.10.14. Authenticated targeted invalidation activated
1.10.15 separately on each origin. Cleanup restored the original private
configuration byte-for-byte and removed the temporary helper.

After reload both origins loaded plugin bundle hash
`29355e5e8f72f6bdb3382d610b3848af` and the new CSS. The native list measured
389 px wide with 329 px of content, a 24 px end gutter and an 83 px row. The
106 px action group appeared on hover; the row, content and next-row position
remained stable. The global Feed also retained its row/content geometry.

A follow-up control found that the global keyboard cursor could fade a row
before it received the shared action group. The corrective selector and its
initial-cursor regression are recorded in **1.10.18**, commit `98e6101bb`.

The first post-install audit matched **94/94**, with Calendar, attachment cache,
