# Mail 1.10.46 deployment

Deployed on 2026-11-19 with Nextcloud 35.0.3.2, NextSnapMail 0.1.17 and SnappyMail 2.38.2. The [release](https://github.com/PiedWeb/NextSnapMail/releases/tag/piedweb-mail-v1.10.46) packages both components from `e910c5da3`.

The installed patch adds `TrashFolder.php` and updates `MailboxOperations.php` and `index.php`. The 97 previous fingerprints matched before installation. The final audit matched all 98 files. LiteSpeed invalidation and a subsequent authenticated request confirmed 1.10.46. Fresh AppData returned plugin cache hash `470f11f5acbe53e39e0ba92b22779a54`. The temporary maintenance plugin was removed.

Mocked IMAP tests exercised an untouched linked account from All my accounts, personal and shared namespaces, ambiguous roles, an explicit override, disabled Trash, Undo and filtered selection. An authenticated smoke test prepared an empty selection with the saved Trash. It performed no move and did not edit account settings.

The private server backup is under `~/nextcloud-customization-backups/mail-1.10.46-20261119T202339Z/`. From that directory, `python3 deploy.py rollback` verifies the three paths, restores the previous two PHP files and removes the new resolver. The same sequence passed on a copy. Use the [web runtime procedure](../../tools/web-runtime-maintenance/README.md) to invalidate the restored PHP and verify the previous version.
