# Mobile selection and menu commands, 24 October 2026

Pied Web **1.10.38** fixes the mobile long-press → More → Mark unread workflow.
Compatibility: Nextcloud **35.0.2**, NextSnapMail **0.1.16**, SnappyMail **2.38.2**.
Versions 1.10.36 and 1.10.37 were intermediate production candidates during this
intervention; only the final 1.10.38 snapshot is published.

## Changes

- A stationary touch's contextmenu can commit selection before the 550 ms timer;
  pointer cancellation retains it. Showing the selection bar can move a different
  row under the finger, so the release click is suppressed across list rows.
  A fresh pointerdown immediately allows an intentional additional selection.
- The mobile Conversations/More nodes are parked outside list-owned headings on
  the native observables' beforeChange notifications. Knockout can then dispose
  old rows/headings without disposing the original menu commands.
- Hidden all-pages selection occupies no space. When available, it wraps below
  the phone controls, keeping count, reminder and Done within 320 px.
- The editor's three native mode/font selects retain 44 px phone targets.
