# Deployment: centered reading column, 2026-10-06

Pied Web **1.10.20** centers the desktop subject, metadata, body, attachment
block, reply actions and conversation history in one reading column. Its
maximum border-box width remains **640 px**, with the existing gutters and
text alignment. The rule applies from **800 px**. Narrow layouts keep their
existing geometry.

The shared rule uses `width:100%`, `max-width:var(--pw-measure)` and
`margin-inline:auto`. Width is explicit because auto cross-axis margins in the
native flex layout otherwise shrink the subject/history around their content,
leaving their left edges misaligned with the body.

Compatibility: Nextcloud **34.0.4**, NextSnapMail **0.1.15**, SnappyMail **2.38.2**.
