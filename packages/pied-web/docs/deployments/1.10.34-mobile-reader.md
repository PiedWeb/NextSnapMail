# Mobile message reader, 22 October 2026

Pied Web **1.10.34** fixes a reader squeezed above the still-visible message list
on phones. Compatibility: Nextcloud **35.0.2**, NextSnapMail **0.1.16**,
SnappyMail **2.38.2**.

## Cause and correction

The engine keeps both mail views mounted and uses `#rl-right.message-selected` to
choose the visible pane. The theme's `#rl-app #V-MailMessageList:not([hidden])`
flex rule outranked the native rule hiding the list. Both panes shared the height,
leaving almost no body text visible. Earlier fixtures explicitly hid the list and
concealed the cascade defect.

Restore the native switch after the flex rule, including desktop single-pane mode.
Phones enforce one pane during transitions from desktop preview layouts and give
the reader the remaining height below the header, with a scrolling message surface
and 16 px side gutters. Desktop previews and native commands remain intact.
Received HTML, mailbox settings and messages were not changed.

## Verification

The new regression failed before the correction and passes afterward. Both views

also pass: **127** browser assertions. The full monorepo suite passes.
Transport and identities are fictional; screenshots stay outside Git.
