# Compose links, 11 October 2026

Deployed Pied Web **1.10.30** on Nextcloud 34.0.4, NextSnapMail **0.1.15** and
SnappyMail 2.38.2. The source checkout carries integrated core 0.1.16; this was
a plugin-only installation. The exact installed combination is recorded in
[1.10.30-runtime-profile.json](1.10.30-runtime-profile.json).

## Behavior and native contract

Bottom Reply/Reply all/Forward, their reader More-menu entries and all New
message controls now carry account-local browser links, including the mobile
header. Plain activation retains native commands, inline replies and existing
draft state. Modified clicks on already-bound native controls bypass KO's
unconditional click cancellation. Enter and Space activate once.

Startup consumes its intent before routing and never repeats on reload. Forward
waits for the exact account/folder/UID and loaded body. All startup compositions
also wait for native AccountsAndIdentities: screens are built before identities
arrive, and an earlier Compose constructor throws. The existing SystemDropDown
account observable changes during that response; a microtask invokes the command
after identities are filled in the same callback. No extra request or identity
copy is introduced. See [INLINE_REPLY.md](../INLINE_REPLY.md).

## Verification

candidate packaging passed. Fictional browser tests passed **80 assertions**:
25 compose-link checks, 29 reply-link checks, seven reply-priority checks and
19 inline-reply checks. They cover existing KO ownership, modified clicks,
disabled actions, delayed identities, source identity, one-shot routing,
iframe targets, both themes and narrow layouts.

stayed closed. The user's already-open composer was preserved in its original
tab. Test autosave timers were cleared before their deadline and test tabs
left without native Close/Save/Send. No real email was sent or saved; no private
content or screenshot is included in the records. Other origins and a physical
phone were not runtime-tested.

0.1.16 checkout. The runtime profile separately verifies the installed 0.1.15
