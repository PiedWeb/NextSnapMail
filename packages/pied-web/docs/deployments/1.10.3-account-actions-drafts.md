# Deployment: account navigation, row actions and draft close 1.10.3

Pied Web **1.10.3** was installed on the n0c production instance on
2026-09-20. Nextcloud remained at **34.0.4**, NextSnapMail at **0.1.14** and
embedded SnappyMail at **2.38.2**. No core application file, account setting,
mailbox content or private configuration was changed.

  `8898d28f6aece0a6661fae03b47d454362f1af2d088e82d4cd22989fa1cbab32`;

## Performance record

- fictional 200-message conversation: **74.6 ms** current median versus
  **217.1 ms** baseline, one server search, zero eager body reads and 199 stable
  keyed cards (about **66% faster**);
- production global Feed: two read-only five-load series, medians **890 ms** and
  **857 ms** for 84 rows with zero failed account. This remains within the prior
  847–863 ms range; the endpoint was not changed by 1.10.3;
- the desktop global Feed still creates only **one** action rail for 84 rows,
  avoiding one hidden SVG/button group per result. Immediate Draft close starts
  persistence on an independent snapshot and does not keep a confirmation modal
  in the interaction path.
