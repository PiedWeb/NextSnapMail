# Progressive conversation reading

Pied Web 1.10.46.1 runs on Nextcloud 35.0.3.2, NextSnapMail 0.1.17 and
SnappyMail 2.38.2. It backports the progressive conversation reader from
`16a5cada0` to the installed 1.10.46 base. The payload changes cover the
conversation JS, the generated PiedWeb CSS and the version-bearing plugin index.

In authenticated Chrome, one opening of the same Inbox conversation per version
measured 1,819 ms before and 830 ms after to the first readable body. The
selected body was ready after 835 and 830 ms respectively. Holding a real
conversation reply in the browser confirmed that the selected body was readable
while the history was pending and stayed active after pointer interaction.

The server suite, 51 conversation reader assertions and three 200-message
stress runs passed with fictional mail. The runtime helper v34 invalidated the
plugin index, verified the LiteSpeed version, restored the configuration and
was removed. The delivered plugin JS SHA-256 is
`51adc8fc0cf05e4767b3b6107599cb2f6b4c9549223172791decc03dc2b58e76`.
The delivered PiedWeb CSS SHA-256 is
`bd0071c23832ac35f2244a89125df68b18c2934fe02251d7b446f441f8d60875`.
