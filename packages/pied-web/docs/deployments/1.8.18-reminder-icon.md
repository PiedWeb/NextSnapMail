# Deployment: reader reminder icon, 1.8.18

Release **1.8.18** was installed on the n0c production instance on 2026-09-19. The
reader reminder remains in the same action group and keeps the same behaviour, but its
clock now uses the common Pied Web toolbar icon pipeline instead of SnappyMail's generic
bordered button surface.

## Cause and correction

`reminders.js` appended the reminder action after `studio.js` had assigned shared
`data-pw-icon` values to the native reader actions. The late button consequently kept its
inline 20 px SVG and inherited the generic `.btn` border and rounded group end.

The action now declares `data-pw-icon="clock"`. Its mask uses the same optical size and
1.8 px stroke as the neighbouring actions, while the inline SVG remains only as a fallback.
The reader group also explicitly keeps a zero radius on this action. No reminder, mailbox or
scheduler logic changed.
