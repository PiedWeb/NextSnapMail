# Deployment: folder and account hierarchy, 2026-10-06

Pied Web **1.10.13** is installed on Nextcloud **34.0.4**, NextSnapMail
**0.1.15** and SnappyMail **2.38.2**. The desktop identity now shows the folder
on its first line and a muted, regular-weight account below it. A small chevron
opens the original native account menu. The surrounding native toolbar is
transparent, with a neutral hover/open state on its trigger.

The design follows Schoger/Wathan, *Refactoring UI*: establish hierarchy through
weight and colour, de-emphasize supporting information and keep tertiary actions
quiet (pp. 38–40, 46, 56, 60). Inbox is labelled in French/English even while its
native folder model is unavailable. Custom folder labels remain native. Mobile
retains its single-line scope and existing account header.
