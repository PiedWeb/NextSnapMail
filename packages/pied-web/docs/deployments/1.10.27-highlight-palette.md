# Deployment: readable highlight colours, 2026-10-11

Pied Web 1.10.27 gives the highlighter 17 light Tailwind 200 suggestions.
Text ink keeps its Tailwind 600 palette. Squire shares one native input and
`datalist`; a capturing colour-action click switches the suggestions before
Squire opens the browser picker, including activation with Enter or Space.
Native formatting, custom colours and existing message content retain their
ownership. Leaving Pied Web restores the original Tableau 10 suggestions.

The sRGB hex values are rounded from the official [Tailwind palette](https://tailwindcss.com/docs/colors).
Contrast is 14.06–18.05:1 with black and 8.84–11.35:1 with `#303030`, above
[WCAG's 7:1 enhanced text contrast](https://www.w3.org/WAI/WCAG22/Understanding/contrast-enhanced.html).
They stay identical across interface themes because the colours belong to the
message HTML, including when the recipient opens it outside NextSnapMail.

## Installation

Compatibility observed: Nextcloud 34.0.4, NextSnapMail 0.1.15, SnappyMail 2.38.2.
The canonical checkout also contains integrated NextSnapMail 0.1.16; that core
update was not part of this palette installation. The exact installed combination
is in [1.10.27-runtime-profile.json](1.10.27-runtime-profile.json).

The first preflight matched all 64 product files of 1.10.24. A concurrent
reply-link deployment then installed 1.10.26. The second preflight detected
that change and refused installation before making any writes. A fresh baseline
matched all 65 files of 1.10.26. The palette rollout preserved that complete
baseline and changed only these paths, installing JavaScript before PHP:

| `plugin/pied-web-ux/index.php` | `43748e1c806f7ca0318fd9fd5aa3ef41a4f5d02cade4cea0e9497370e1e6c5c1` |

The index change only advances the cache version from 1.10.26 to 1.10.27.
Native CLI compilation reported 687472 JavaScript bytes and plugin hash
`a81cc484d7cdcd670d9c2963fab6f65d`, with both palette markers present.

An authenticated LiteSpeed request initially executed the old 1.10.26 class.
The temporary maintenance helper used the fresh `maintenance-v27` path.
Invalidation followed by a new request confirmed 1.10.27. Cleanup restored
private configuration byte-for-byte and removed the helper. Configuration
and its backup remain exclusively on the host.
