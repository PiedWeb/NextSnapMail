# Deployment 1.7.32, 2026-09-15

The compact desktop sidebar is remembered between page loads. SnappyMail
initialises `leftPanelDisabled` from the viewport at every start, so collapsing
the folder panel never survived a reload. An explicit desktop toggle now writes
`pw-left-panel` in the browser's `localStorage`, and the choice is reapplied
through the native `toggleLeftPanel` of the `MailFolderList` view model while
that pane is still being built. No server setting is written and no native
contract is changed.
