## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.24-20260914T180204Z/deploy.py" rollback
```

The script requires all 35 current 1.7.24 fingerprints and verifies the saved
1.7.23 files before restoring only the stylesheet and PHP entry point, with
PHP last. Then follow `tools/web-runtime-maintenance/README.md` to invalidate
the restored PHP class in the authenticated Web runtime and reload Mail.
