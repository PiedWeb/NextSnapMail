The desktop list now also has a faint gray line between messages, and row checkboxes align horizontally with Select all while remaining vertically aligned with stars. All new CSS stays inside the `min-width: 1200px` media query.

Before installation, Nextcloud 34.0.4, NextSnapMail 0.1.11 and embedded SnappyMail 2.38.2 matched every one of the 35 files in the 1.7.12 manifest. The guarded install and rollback scripts, both manifests and staged assets are outside the web root at `~/nextsnapmail-staging/pied-web-ux-1.7.13-20260914T122210Z/`. ## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.13-20260914T122210Z/rollback.py"
```

The script requires all 35 installed files to match 1.7.13, verifies the saved 1.7.12 index and stylesheet, then restores those two files. Follow `tools/web-runtime-maintenance/README.md` to invalidate the restored PHP class in authenticated LiteSpeed Web runtime and reload Mail. No message, account or calendar data is involved.
