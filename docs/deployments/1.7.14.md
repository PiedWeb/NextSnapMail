# Deployment 1.7.14, 2026-09-14

This release adds desktop-only read-state dots, hover/focus stars and a fixed right-hand attachment column. The dot calls SnappyMail 2.38.2's native seen/unseen action for the message in the active list; it does not select or open the row. The established mobile layout and visible star remain unchanged.

Before installation, Nextcloud 34.0.4, NextSnapMail 0.1.11 and embedded SnappyMail 2.38.2 matched all 35 files in the 1.7.13 manifest. The guarded deployment changed only `plugin/pied-web-ux/list-metadata.js` (SHA-256 `8d62f93e83fa8cc83778c846718658c5bd1952ee3ed599a4b9f79650935203c9`), `theme/PiedWeb/snappymail/style.css` (SHA-256 `7cc4c8cb2ce4747f89fd326f31f9ba6a5a2fbf0680e4ee2f31a7a44ee019a668`) and version-bearing `plugin/pied-web-ux/index.php` (SHA-256 `e3a8ffcdd556c5216cbbf8bbb2e51192a974a71227e462321a2b46debdc0892b`). It installed JS and CSS before PHP and verified all 35 new hashes. The server staging directory is `~/nextsnapmail-staging/pied-web-ux-1.7.14-20260914T124000Z/`; the exact previous files, both manifests and rollback script are at `~/nextsnapmail-backups/pied-web-ux-v1.7.14-20260914T124000Z/`, outside the web root.

LiteSpeed initially reported the old 1.7.13 PHP class despite the installed 1.7.14 files. The authenticated, temporary runtime hook invalidated the four fixed plugin PHP files. A distinct web request then reported 1.7.14. Cleanup restored the original `application.ini` byte-for-byte and removed the temporary plugin. The public stylesheet URL served the final SHA-256. A reloaded authenticated Chrome page showed both CSS and metadata version 1.7.14; its served plugin bundle carried the new dot code and virtual Sent code without the temporary hook. The browser bundle cache hash was `573273c895e9fc9035dd31bb11d0a979`.

Read-only live browser checks confirmed the desktop dot states and labels, aligned checkbox, native grid, attachment column and star reveal on hover. The native folder toggle still changed the rail from 248 to 72 px and back. No production message was opened, marked, sent, moved or captured. Fictional browser tests exercised the native action call and keyboard toggle, attachment geometry, star hover and mobile targets; PHP/JS syntax, five Python tests and reproducible theme/manifest verification passed. A 390 px fictional mobile capture was pixel-identical to 1.7.13. See `docs/previews/1.7.14/`.

## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.14-20260914T124000Z/rollback.py"
```

The script requires all 35 installed files to match 1.7.14, verifies the saved 1.7.13 files and restores only those three files. Then follow `tools/web-runtime-maintenance/README.md` to invalidate the restored PHP class in the authenticated LiteSpeed web runtime and reload Mail. No account, message or calendar data is involved.
