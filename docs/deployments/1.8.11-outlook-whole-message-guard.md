# Deployment 1.8.11: keep whole Outlook messages visible, 2026-09-18

Outlook-style history is now folded only when real visible message content precedes the
four-field mail header. If that header starts the body, the complete message stays visible.
Hidden preheaders and tracking markup do not count as a current answer and cannot cause the
whole mail to disappear behind the quote disclosure.
