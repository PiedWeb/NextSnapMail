# Deployment 1.8.17: mail reminders, 2026-09-18

Pied Web Mail can now defer one Inbox message, a conversation or a selected group. The mail
waits read in a visible `Reminders` IMAP folder and returns to Inbox unread at the chosen time,
even with no browser open. The existing `piedwebmailscheduler` app advances from 1.0.3 to 1.1.0
and wakes reminders in the same mailbox pass as scheduled sends.

This release also includes the preceding source commits that refine composer geometry, hierarchy
and utility controls. Plugins 1.8.15 and 1.8.16 were unpublished deployment intermediates. The
theme evolved after each compiled CSS cache had been created, so the final version is 1.8.17:
its new plugin key makes the complete theme compile reachable without deleting a shared cache.

## Rollback

Disable `piedwebmailscheduler` first to stop both scheduled delivery and automatic reminders.
Restore the five changed scheduler files from its backup, set its `installed_version` back to
1.0.3, then enable it. Restore plugin `index.php`, `ux.css` and `ux.js` from the 1.8.14 plugin
backup, remove only the added `Reminders.php` and `reminders.js`, and restore theme
`snappymail/style.css` from the theme backup. Install the restored index last.

Run the authenticated targeted runtime procedure for the restored PHP, reload Mail and confirm
the old plugin bundle and compiled theme. Messages already in `Reminders` are not deleted by a
code rollback: move them to Inbox and mark them unread before or after restoring, or temporarily
keep scheduler 1.1.0 enabled until they wake. The feature owns no message database or content
file; backups contain code only.
