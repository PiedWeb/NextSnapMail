## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.5-20260913T135423Z/rollback.py"
```

The script verifies current and backed-up fingerprints before restoring the
two 1.7.4 files. Then follow `tools/web-runtime-maintenance/README.md` to
invalidate Web OPcache for `index.php` in an authenticated session, reload
Mail and verify the served bundle and DOM. Keep the private backup outside
the web root; account, Sieve, calendar and user files are not involved.
