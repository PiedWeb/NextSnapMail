## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.15-20260914T131022Z/rollback.py"
```

The script requires all 35 installed files to match 1.7.15 and verifies the saved 1.7.14 files before restoring only the four changed files. Then follow `tools/web-runtime-maintenance/README.md` to invalidate the restored PHP class in the authenticated LiteSpeed web runtime and reload Mail. No account, message or calendar data is involved.
