## Behavior and performance

The hook runs only for page one of the ordinary `INBOX` feed when the account preference is
enabled. It augments the already executing native `MessageList` response, reusing the same
authenticated IMAP connection, sort and UID/thread caches. One `UNSEEN` search fetches only
unread headers. If the native page already covers every unread UID, the supplementary query
is skipped. The browser revives one merged native collection and removes those gathered UIDs
from later pages.

Searches, opened thread detail and non-Inbox folders remain outside the hook. An exception in
the optional collection leaves the native response intact. Very large sets use SnappyMail's
999-row native batches on the same connection.
