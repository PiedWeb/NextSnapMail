with a chronological conversation stack in the opened reader. The owner

sent, and allow one-click access to all earlier messages. A structural check

## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.20-20260914T162550Z/deploy.py" rollback
```

The script verifies all current 1.7.20 payload hashes and the saved interim
1.7.19 files before restoring only the three changed files. Then follow
`tools/web-runtime-maintenance/README.md` to invalidate the restored PHP
class in the authenticated Web runtime and reload Mail. The earlier 1.7.19
backup at `~/nextsnapmail-backups/pied-web-ux-v1.7.19-20260914T155350Z/`
restores the exact original 1.7.18 files if that older baseline is needed.
