# Deployment 1.7.23, 2026-09-14

conversation cards, calendar import and attachments, while preserving the
established phone layout. The theme now centers the Conversations icon, puts
the conversation count above the attachment column, replaces the broken
native text-file glyph with a paperclip, and makes the native back-to-list
control compact. The reader uses a tighter header, a divider before its reply
actions, a secondary calendar action after message metadata, and compact file
tiles. Folded cards show a one-line plain-text body excerpt instead of another
copy of the subject. Missing excerpts are fetched only when cards approach the
viewport, at most two requests concurrently. SnappyMail's `Message` endpoint
uses IMAP `BODY.PEEK`, so this does not mark a message read.

## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.23-20260914T174316Z/deploy.py" rollback
```

The script requires all 35 current 1.7.23 fingerprints and verifies the saved
1.7.22 files before restoring only the four changed files, with PHP last.
Then follow `tools/web-runtime-maintenance/README.md` to invalidate the
restored PHP class in the authenticated Web runtime and reload Mail.
