# Deployment 1.7.52, 2026-09-16

One correction to the release installed a few hours earlier: the hour goes back
to hidden in the desktop message list. 1.7.38 had restored it inside the
seventeen-release *Refactoring UI* pass, on the grounds that a timestamp is data
rather than decoration. Seen on the real mailbox, it was data already on screen
— the rows are grouped under "aujourd'hui", "hier" and a spelled-out date — and
on this instance the row timestamps read "il y a 1 heure", so the column
repeated the heading above it in a longer form. Two files carry the change,
`index.php` and the theme stylesheet.

## Installation

Files were staged privately in `~/.pw-stage-1.7.52` (mode 700), their bytes
compared with the 1.7.52 manifest — both equal — and the server's own `php -l`
accepted the new `index.php` before any write. The stylesheet was installed
first and `index.php`, which announces the version, second.

Installed hashes equal the manifest across all 40 payload files, with no drift,
nothing missing, no foreign file and mode 644 throughout. The staging directory
was removed.

Workers were recycled with `pkill -u robindfr lsphp` (15 workers before, 2
after) followed by a warm-up request, `status.php` 200 in 0.16 s. The served
plugin bundle key changed from `1ef81c5b50a93ce155a6bdab76d60589` to
`61070cefa1e48e4ee8d90d5f2d51b773`, which remains the only reliable proof of web
activation with `opcache.validate_timestamps=0`, and is also what makes the
recompiled stylesheet reachable.
