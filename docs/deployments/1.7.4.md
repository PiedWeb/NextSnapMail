## Rollback

On the n0c host, run:

```sh
python3 "$HOME/nextsnapmail-backups/pied-web-ux-v1.7.4-20260913T133016Z/rollback.py"
```

The script checks that the four installed files still match 1.7.4 (or the
backed-up 1.7.3 bytes) before restoring them. Then follow
`tools/web-runtime-maintenance/README.md` to invalidate Web OPcache for
`index.php` in an authenticated session, reload Mail and verify the served
bundle and DOM. Keep the private backup outside the web root; no account,
Sieve, calendar or user files are part of it.
