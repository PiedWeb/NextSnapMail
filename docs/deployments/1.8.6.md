# Deployment 1.8.6, 2026-09-18

This release adds upstream **Squire 2.4 (test)** as an opt-in visual editor while
keeping SnappyMail's native **Squire** as the default. It also installs the Tailwind
600 color suggestions and makes a successful background reply refresh an open
conversation and its answered state immediately.

## Preflight

Production reported Nextcloud 34.0.4.1 (display version 34.0.4), NextSnapMail 0.1.11,
embedded SnappyMail 2.38.2 and plugin 1.8.5. Nextcloud was installed, outside
maintenance mode and needed no database upgrade.

The four existing files replaced by 1.8.6 matched the committed 1.8.5 manifest
exactly: `background-send.js`, `composer-toolbar.js`, `conversation-thread.js` and
`index.php`. The five Squire files were absent. The complete read-only audit had the
expected nine 1.8.6 mismatches and no other drift; Calendar, `.htaccess`, the private
attachment-cache duration and every unrelated tracked payload remained expected.

Complete backups outside the Web root, before any write:

- `~/nextsnapmail-pied-web-backups/pied-web-ux-1.8.5-20260917T221639Z/`
- `~/nextsnapmail-pied-web-backups/PiedWeb-theme-1.8.5-20260917T221639Z/`

The theme was backed up as required but not changed by this deployment.

## Installation

Nine plugin files were staged privately in
`~/.pw-stage-1.8.6-20260917T221639Z`. All nine SHA-256 fingerprints matched the
1.8.6 manifest and the server PHP accepted `index.php`. The eight assets were installed
first, then the version-bearing `index.php`, all mode 644. The private stage was removed
after verification.

LiteSpeed initially had four account PHP workers. They were recycled after installation;
the immediate warm-up request briefly returned 503 while the pool restarted, then three
workers were present and `status.php` returned 200 on the next request.

The source commit is `8fb07ca`, tagged `v1.8.6`. The GitHub release contains
`nextsnapmail-pied-web-1.8.6.tar.gz`, SHA-256
`a93a7d3c75a24ac969350bdc1d72b6dfdf83b2d547be82c7ca57544a55258f9e`, and its checksum
file.

## Verification

- `tools/verify.py`: 50 payload files, reproducible theme, JavaScript and PHP syntax pass.
- Python diagnostics: 5 pass.
- Browser fixtures: Squire trial 10, composer images 22, toolbar and palette 26,
  Markdown 25, background-send 15 and conversation refresh 24 checks pass.
- Final server audit: 77 of 77 tracked files match; versions, Calendar description,
  `.htaccess` and attachment-cache duration are expected.
- Authenticated production runtime: the new constructor is loaded without replacing
  native `window.Squire`; General settings visibly offer exactly **Squire** and
  **Squire 2.4 (test)**. The saved choice remains **Squire**, so no user preference was
  changed during validation.

The authenticated check only navigated to General settings. It did not open, read,
compose, save or send a message.
