# Production deployment 1.8.9 — inline reply and Reply all priority, 2026-09-18

This release completes the targeted 1.8.6.2 unread-feed deployment with the pending
1.8.7–1.8.9 reader work. Reply and Reply all now use the native composer inline in the
active Inbox conversation, with an Expand control for the full popup. A successful reply
refreshes the feed and conversation so the new Sent message can become the last visible
message. Group messages put Reply all first and emphasize it in the top toolbar; their
bottom primary action is Reply all, beside the secondary Reply and Forward actions.

## Preflight and backup

Production reported Nextcloud 34.0.4.1 (display version 34.0.4), NextSnapMail 0.1.11,
embedded SnappyMail 2.38.2 and plugin 1.8.6.2. Nextcloud was installed, outside maintenance
mode and needed no database upgrade. The 1.8.6.2 unread endpoint and browser assets already
matched the 1.8.9 manifest, so this deployment changed only the seven remaining files.

Complete plugin and theme backups were made outside the web root before writing:

- `~/nextsnapmail-pied-web-backups/pied-web-ux-1.8.6.2-20260917T232632Z/`
- `~/nextsnapmail-pied-web-backups/PiedWeb-theme-1.8.6.2-20260917T232632Z/`
