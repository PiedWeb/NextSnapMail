# Product

## Register

product

## Users

Robin uses NextSnapMail and the surrounding Nextcloud apps for personal and work tasks, on desktop and mobile. Existing decisions and native behavior contracts are recorded in docs/CONTEXT.md.

## Product Purpose

Make reading, composing and planning clear and efficient. Extend the Pied Web workspace to Calendar: give the active app the full window, with the native app grid beside the event filter.

## Brand Personality

Quiet, clear, practical. Roundcube's readable folder navigation and Gmail's familiar editing controls are references from the user's brief.

## Anti-references

No nested application frames, repeated global headers, decorative containers or oversized secondary actions. The user explicitly rejected the Nextcloud wrapper around Mail and Office.

## Design Principles

- Give the active task the viewport.
- Preserve native commands, keyboard navigation and data ownership.
- Keep primary actions distinct and secondary metadata quiet.
- Reuse the native app launcher; do not duplicate the installed app list.
- Keep every customization versioned, recoverable and separately scoped.

## Accessibility & Inclusion

Desktop and mobile are required. Preserve French/English native labels, visible keyboard focus, Nextcloud light/dark preferences, and comfortable touch targets. No theme change should alter user content.
